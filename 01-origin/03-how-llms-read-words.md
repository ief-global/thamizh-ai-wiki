# AI எப்படி சொற்களைப் படிக்கிறது? — "டோக்கன்" விளக்கம்
# How LLMs read words — tokens, explained without IT

> **In brief (English):** LLMs read text as "tokens". English words map to clean whole tokens; Tamil's
> agglutinative words get shattered into meaningless fragments — costing 3–5× more tokens, degrading
> reasoning, and breaking semantic search. This is the "token explosion" problem.

## மணிமாலை உவமை / The bead-chain analogy

AI ஒரு வாக்கியத்தை நம்மைப் போல எழுத்து-எழுத்தாகவோ சொல்-சொல்லாகவோ படிப்பதில்லை. உரையை
**"டோக்கன்" (token) எனும் துண்டுகளாக** நறுக்கி, ஒவ்வொரு துண்டையும் ஒரு மணியாகக் கோர்த்து, அந்த
மணிமாலையைத்தான் "படிக்கிறது". இந்த நறுக்கும் கத்தி (tokenizer) **பெரும்பாலும் ஆங்கில உரையை வைத்து**
வடிவமைக்கப்பட்டது.

## ஆங்கிலத்தில் என்ன நடக்கிறது?

ஆங்கிலம் **தனிச்சொல் மொழி** (analytic): இலக்கண உறவுகள் தனித்தனிச் சொற்களாக வரும்.

```
"in the house"  →  [in] [the] [house]     — 3 சொல், 3 சுத்தமான டோக்கன்
```

ஒவ்வொரு டோக்கனும் ஒரு முழுப் பொருளுள்ள சொல். AI-க்கு எளிது.

## தமிழில் என்ன நடக்கிறது?

தமிழ் **ஒட்டுநிலை மொழி** (agglutinative): வேர்ச்சொல்லுடன் உருபுகள் ஒட்டி **ஒரே சொல்லாக**
இணைகின்றன — அதுவும் புணர்ச்சி விதிகளால் வடிவம் மாறி.

```
வீடு + இற்கு + உள்  →  "வீட்டிற்குள்"      — ஒரே சொல், முழு அர்த்தத்துடன்
```

ஆனால் ஆங்கிலத்துக்காக வடிவமைத்த கத்தி இந்தச் சொல்லின் **இலக்கண எல்லைகளை அறியாது**. நறுக்கும்போது:

```
"வீட்டிற்குள்"  →  [வீ] [ட்] [டி] [ற்] [கு] [ள்]   — பொருளற்ற 6+ சிதறல்கள்
```

வேர் "வீடு" எங்கும் இல்லை; "உள்" எனும் பொருளும் இல்லை. **மணிமாலையில் மணிகள் உடைந்த கண்ணாடித்
துகள்களாக.**

## இதனால் மூன்று விளைவுகள்

1. **செலவு / இட விரயம்:** அதே கருத்தைச் சொல்ல தமிழுக்கு **3–5 மடங்கு** டோக்கன்கள் தேவை. AI-யின்
   "நினைவு இடம்" (context window) விரைவில் நிரம்புகிறது; கட்டணமும் கூடுகிறது.
2. **சிந்தனைத் தரம் வீழ்ச்சி:** பொருளற்ற நீண்ட சிதறல் வரிசைகளில் AI-யின் தர்க்கம் தடுமாறுகிறது;
   பல மாதிரிகள் உள்ளூர "ஆங்கிலத்தில் மொழிபெயர்த்து" யோசிக்க முயல்கின்றன — பிழைகள் கூடுகின்றன.
3. **தேடல் பிழை (RAG):** AI-தேடலில் சொற்கள் "பொருள்-வெளியில்" அருகருகே இருக்க வேண்டும். சிதறிய
   துண்டுகளின் பொருள்-முகவரி தவறாக அமைவதால், தமிழ்த் தேடல்/மீட்டெடுப்பு துல்லியம் குறைகிறது.

## தீர்வுக்கான திசை

கத்தியை மாற்றுவது = AI மாதிரியையே மறு-பயிற்சி செய்வது — **கோடிக்கணக்கான செலவு**, நமக்குச்
சாத்தியமில்லை. மாற்று வழி: **சொல்லை முறையாகப் பிரித்துத் தரும் ஒரு "மொழி அறிவாளியை"** AI-யின்
பக்கத்தில் நிறுத்துவது. AI "வீட்டிற்குள்" பார்த்ததும் அந்த அறிவாளியைக் கேட்கும்; அவர்
**வீடு + இற்கு (4-ஆம் வேற்றுமை) + உள்** என்று விதிச் சான்றுடன் பிரித்துத் தருவார்.
